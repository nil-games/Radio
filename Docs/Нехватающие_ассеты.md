# Нехватающие ассеты

> Что в игре сейчас стоит заглушкой и чем её заменить. Ведёт Claude: при реализации
> новой сцены дописывает строки, при замене заглушки — переносит строку в «Готово».
> Начато 22.10.2026 при реализации ночи 2 (сценарии — `Docs/Диалоги/Ночь_2/`).
>
> **Как читать «Куда положить».** Звуки и музыка из диалогов ищутся по **имени клипа**:
> положи клип с этим именем в список кассет нужного кассетника (`DialogueSystem` → `MoodDeck`
> для музыки, `SfxDeck` для звуков), и он заиграет сам — без правки Yarn. Пока клипа нет,
> в консоли предупреждение «записи … нет в списке кассет — заглушка, играет тишина».
