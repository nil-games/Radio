## 3. Системы, которые сделаны в этой сессии

- **Время с ночами.** `GameTimeMark.at` = «ЧЧ:ММ» (ночь 1) или «ЧЧ:ММ:НН».
  `TimedEvent` сравнивает сквозной счёт `TimeManager.TotalMinutes`.
  `DebugJumped` передаёт сквозные минуты. `TimeManager.BeginNight / BeginNextNight /
  DebugBeginNight`, `DebugClock` = «ЧЧ:ММ:НН». Задачи (`Tasks.asset`, поле time)
  и `StoryBeats.asset` (поле night) тоже понимают ночи.
- **Отладка:** правый Ctrl — сводка; 6 цифр ЧЧММНН — в любую ночь, 4 цифры — время
  в текущей ночи (применяется через ~1,2 с).
- **MinigameHost:** список «Запуски» (эфиры) на префабе `Prefabs/UI/WirePuzzle`,
  у каждого `from` (ЧЧ:ММ:НН), уровни, задача при запуске, `nextTask` после победы,
  флаг, время после победы. Эфир выбирается автоматически по часам,
  «Начать эфир» на микшере открыт только когда есть непройденный эфир (`broadcast_ready()`).
- **TapeDeck** с именем команд: `tape` (микшер), `cassette` (плеер, песни ночи 1),
  `onair` (DialogueSystem/OnAirDeck — песни в эфире ночи 2). Нет клипа — предупреждение
  и тишина (заглушка).
- **PhoneRinger:** список звонков `rings` (ЧЧ:ММ:НН + задержка).
- **EntranceDoor:** список гостей `visitors` (DoorKnocker + узел Yarn).
  Гости: Зина н1 (00:30), кошка н1 (04:00), Зина н2 (01:30:02), сантехник н2 (02:30:02).
- **DoorVisitorView:** 3D-кошка на площадке, анимация Seat с открытием двери.
- **Кошка в квартире:** `CatHome` (ActivateOnFlag по `cat_inside` включает кошку,
  Miska, Feed), `CatWander` + NavMesh (`CatNavMesh`, агент «Cat»), точки `CatSpot`.
  Анимации: Walk, Seat, Lie (= Seat, пока нет клипа). Файлы в `Prefabs/Characters/Cat`.
- **SleepSequence:** «Лечь спать» на диване (≥ 05:00) → затемнение → узел
  `Night{N}_Dream` на чёрном экране (поле Dream Image под картинку) → «Ночь N завершена»
  → «Ночь N+1 / 00:00» → игрок у дивана (`WakePoint`) → узел `Night{N+1}_Wake`.
  Поле `wakeSound` — будильник (пусто).
- **InspectableItem** («3D просмотр»): Alenka, записка `e (4)` (без вращения).
- **ControlsHint** — «F - Взаимодействие / Отмена» справа внизу.
- **NumberPrompt:** `<<ask_number var>>` — ввод 6 цифр, ответ строкой в `$var`.
- **RadioVoiceTrigger** на Radio: при задаче `n2_radio`, включённом радио и частоте
  96.6 ± 0.3 МГц начинается `Night2_AlisaRadio`. `<<radio_off>>` выключает радио.
