## Концепция

Игрок соглашается на неделю подменить друга Серёгу, ночного ведущего маленькой провинциальной радиостанции. Работа кажется простой: ставить музыку, запускать рекламу, принимать звонки, читать объявления, следить за аппаратурой. Но когда игрок приходит на первую смену, Серёги уже нет — а его куртка, ключи, еда, кассеты и записная книжка остались на рабочем месте. Постепенно выясняется, что он никуда не уехал, а пропал.

Одновременно оборудование начинает ловить странное. Через необычные частоты и неправильные комбинации аппаратуры можно услышать старые эфиры, чужие разговоры, голоса пропавших людей, события, которые ещё не произошли, и неизвестную частоту **103.1**.

За семь смен игрок должен разобраться, что случилось с Серёгой, попутно вмешиваясь в истории постоянных слушателей и решая, какой информацией воспользоваться, кому верить и какие правила нарушить.

### Core loop

Игрок приходит в студию → изучает расписание и последствия прошлой ночи → ведёт эфир, принимает звонки, работает с техникой. Между обязательными блоками есть свободные окна: исследовать радиоточку, вещи Серёги, странные частоты, бытовые предметы. Ночью происходят сюжетные и мистические события, игрок принимает решения, в 06:00 смена заканчивается. Последствия решений проявляются в следующую ночь.

Игровое время двигается **только от действий игрока** — пока он осматривается или думает, часы стоят.

### Дизайн-пиллары

- **Работа на радио — настоящий геймплей.** Игрок реально крутит микшер, кассетники, телефон и эфирную сетку, а не выбирает реплики в диалогах.
- **Информация — главный ресурс.** Игрок узнаёт чужие секреты, события прошлого и возможного будущего, и решает, кому их передать.
- **«Не та клавиша».** Неправильное действие иногда полезнее правильного: сначала ошибка создаёт проблему, потом открывает скрытый слой игры.
- **Персонажи и последствия.** У постоянных слушателей свои сюжетные линии; игрок может помогать, мешать, скрывать информацию, вмешиваться в судьбы.
- **Уют + мистика.** Радиоточка должна быть местом, где приятно находиться: тёплый свет, музыка, чай, дождь за окном, гул техники. Паранормальное работает через контраст с уютом — студия не должна превращаться в типичный хоррор-интерьер.

### Структура ночей

| Ночь | Название | Что добавляется |
|---|---|---|
| 1 | Подмена | Туториал, базовая работа с эфиром, первый странный звонок |
| 2 | Не та частота | Поиск частоты, обнаружение 103.1 |
| 3 | Запись | Работа с записью, кассета Серёги |
| 4 | Эхо | Информация о событии до того, как оно произошло |
| 5 | Исчезновение | Восстановление последней смены Серёги |
| 6 | Выбор | Конфликт персонажей из-за аномалии |
| 7 | Последний эфир | Ключевая комбинация и развязка |

### Персонажи

**Серёга** — пропавший ведущий, раскрывается через вещи и записи. **Викторыч** — начальник станции, бытовая сторона истории. **Север** — радиолюбитель, знает о 103.1 больше других. **Лена** — голос на необычной частоте. **Миша** — подросток-слушатель. **Участковый** — связывает эфир с событиями города. **Дальнобойщик** — ночной слушатель, окно во внешний мир.

### Scope

**MVP:** одна студия, одна ночь, микшер, кассетник, телефон, эфирное расписание, два обычных звонка, один сюжетный, одна странная частота, одна небольшая загадка, несколько бытовых взаимодействий.

**Vertical slice:** 20–30 минут первой ночи. Должен доказать две вещи — интересно ли работать на радио и приятно ли просто находиться в студии между событиями.

**Приоритеты:** P0 — interaction, радио, телефон, кассеты, расписание, диалоги, сюжет первой ночи, sound design. P1 — механика частот, несколько NPC, бытовые интеракции, последствия решений. P2 — поведение кошки, доп. помещения, телевизор, секретные события.

**Не вырезать раньше времени:** основную радио-механику, Серёгу, звонки, странную частоту, контраст уюта и мистики.

### Что нужно установить

| Инструмент | Версия | Зачем |

| **Unity** | **6000.4.1f1** | Основной движок |

### Клонирование и начало работы

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/nil-games/Radio.git Radio100
cd Radio100

# 2. Инициализировать Git LFS (один раз на машине)
git lfs install

# 3. Перейти на свою ветку
git checkout dev-nikolas

# 4. Открыть проект в Unity 6000.4.1f1:
#    Unity Hub -> Add -> Add project from disk -> папка Radio100
```

> Есть ещё один обязательный шаг — подключение Unity-мерджера сцен.
> Он описан в [CONTRIBUTING.md](CONTRIBUTING.md). Без него конфликт в сцене ломает её насовсем.

## Правила командной работы

Полная инструкция — **[CONTRIBUTING.md](CONTRIBUTING.md)**. Прочитай её перед первым коммитом.

Коротко самое важное:

- **`main` — всегда рабочая сборка.** Напрямую в неё пушит только Nil.
- Остальные вливают свои ветки в `main` **через Pull Request**, который одобряет Nil.
- Каждое утро подтягивай `main` к себе в ветку. Свою ветку пушь часто — хоть каждый час.
- **Перед правкой любого `.unity`-файла предупреди команду в чате.** Одновременная правка сцены двумя людьми = конфликт, который нормально не разрешается.
- `Asset Serialization Mode = Force Text` — уже включено в репозитории, приедет само.
- Формат коммита: `feat: добавил систему управления` / `fix: починил прыжок`.

## Версии пакетов — не понижать

В `Packages/manifest.json` версии подняты относительно того, что кладёт шаблон Unity Hub. Шаблон «Universal 3D» собран под Unity 6.0 и на 6000.4.1f1 **не компилируется**:

```
InputSystemPluginControl.cs(47,25): error CS0117:
'BuildTarget' does not contain a definition for 'ReservedCFE'
```

Актуальные версии — Input System 1.19.0, URP 17.4.0, Timeline 1.8.11. Если Package Manager предложит «откатить к версии из шаблона» — не соглашайся.

## MCP for Unity (CoplayDev)

Пакет `com.coplaydev.unity-mcp` добавлен в `Packages/manifest.json`.

Для работы MCP-сервера нужен **Python + uv**:

```powershell
pip install uv
uvx --from mcpforunityserver==9.7.3 mcp-for-unity
```

В Unity: `Window → MCP For Unity → Server Window`.
