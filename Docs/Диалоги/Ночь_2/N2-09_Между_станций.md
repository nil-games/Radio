# N2-09 Между станций

**Ночь:** 2 · **ID расписания:** N2-09 · **Время:** после звонка Севера (03:30) и до сна (06:00); если дядя Коля в 05:00 снимет провод — дальше не поймать, до сна
**Участники:** Я
**Запуск:** игрок сам настраивает приёмник (02.8). Необязательно. Только если заземление не снято (`ACTION_N2_GROUND_REMOVED = false`, N2-05). Подсказки — листок Серёги с обведённой 96,6 (тайник, N2-05), задача «Проверить радио» после звонка Севера и фраза Алисы из первого сна «Ищи меня между станций».
**Сюжет:** решение автора (19.10.2026): во второй ночи на радио можно добавить что-то от Алисы; сон будет в любом случае.

---

*(На шкале, около 96,6 — 💡 частота будущего голоса Алисы, — помехи вдруг складываются в звук: далёкая музыка карусели, плеск воды, скрип качелей. Тот самый парк из сна. Голоса нет.)*

**Я:** …Это же оттуда. Из сна.

*(Если игрок уводит ручку — звук пропадает. Если возвращается — его уже нет: только обычный шум.)*

Флаг: `STORY_N2_RADIO_PARK_FOUND = true`. Последствия: 💡 во сне N2-10 Алиса говорит «Ты нашёл меня» (+1 к сближению с Алисой, счётчик 01.6). Если не нашёл — сон тот же, без этой реплики.

---

*Для команды:* частота 96,6 ± 0,3 уже есть в приёмнике (голос Алисы в демо); здесь на ней только звук парка. Срабатывает один раз. Если провод сняли — на 96,6 только ровный шум; 💡 мысль героя: «Глухо. Как Серёга говорил».
